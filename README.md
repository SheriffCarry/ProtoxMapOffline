# Offline ProtoxMapmaker Client

This is an Electron client for [Protox Mapmaker](https://mapmaker.protox.io) with offline capabilities.
This was 100% generated by AI.

## Features
- **Offline Support**: Caches all visited pages and resources. If you lose internet connection, it loads the cached version.
- **LocalStorage Sync**: Keeps your settings and data synced between online and offline sessions by saving `localStorage` to `storage.json`.
